UNIDAD 1 › ERROR ABSOLUTO
Error Absoluto

Diferencia entre el valor verdadero y el valor aproximado, sin importar el signo.

📐
Tipo
Diferencia directa
📏
Unidades
Mismas que la magnitud

Definición y Fórmula

El error absoluto mide cuánto difiere el valor aproximado del valor real, en las mismas unidades de la magnitud medida.

Ea = |Valor_verdadero − Valor_aproximado|

Error Relativo

Error absoluto dividido entre el valor verdadero; mide el error en proporción a la magnitud real.

📊
Rango
0 a 1 (adimensional)

Definición y Fórmula

El error relativo normaliza el error absoluto respecto al valor verdadero, permitiendo comparar errores de diferentes magnitudes.

Er = |Valor_verdadero − Valor_aproximado| / |Valor_verdadero|

UNIDAD 2 › BISECCIÓN
Método de Bisección

Divide el intervalo a la mitad en cada iteración para localizar la raíz de una función continua.

⚡
Convergencia
Lineal — Segura
✅
Requisito
f(a)·f(b) < 0

Fórmulas

Xr = (Xl + Xu) / 2 Si f(Xl)·f(Xr) < 0 → nueva Xu = Xr, sino nueva Xl = Xr

Calculadora — ingresa f(x) y el intervalo

Escribe la función usando JavaScript: Math.sin(x), Math.exp(x), Math.pow(x,2), etc.
① f(x)
② a (Xl)
b (Xu)
Tolerancia
Máx. iter

Código Python

Biseccion.py
def biseccion(f, a, b, tol=1e-4, max_iter=50):
    if f(a) * f(b) > 0:
        return None
    for i in range(max_iter):
        xr = (a + b) / 2
        if abs(f(xr)) < 1e-14 or (i > 0 and abs((xr - a) / xr) < tol):
            return xr
        if f(a) * f(xr) < 0:
            b = xr
        else:
            a = xr
    return (a + b) / 2

UNIDAD 2 › FALSA POSICIÓN
Falsa Posición

Usa interpolación lineal entre los extremos del intervalo para estimar la raíz de manera más eficiente que bisección.

🎯
Precisión
Mayor que bisección
📉
Técnica
Interpolación lineal

Fórmula

Xr = Xu − [f(Xu)·(Xl − Xu)] / [f(Xl) − f(Xu)]

Calculadora

Usa Math.sin(x), Math.cos(x), Math.exp(x), Math.log(x), Math.pow(x,n)
① f(x)
② a
b
Tolerancia
Máx. iter

Código Python

FalsaPosicion.py
def falsa_posicion(f, a, b, tol=1e-4, max_iter=50):
    if f(a) * f(b) > 0:
        return None
    xr = a
    for i in range(max_iter):
        xr_old = xr
        fa, fb = f(a), f(b)
        xr = b - fb * (a - b) / (fa - fb)
        if abs(f(xr)) < 1e-14 or (i > 0 and abs((xr - xr_old) / xr) < tol):
            return xr
        if fa * f(xr) < 0:
            b = xr
        else:
            a = xr
    return xr

UNIDAD 3 › ELIMINACIÓN GAUSSIANA
Eliminación Gaussiana

Método directo para resolver Ax=b reduciendo la matriz a forma triangular superior y aplicando sustitución hacia atrás.

🔢
Tipo
Directo — O(n³)
📐
Sistema
Ax = b
💻
Lenguaje
Java

Fórmulas

Factor: m(i,k) = A[i][k] / A[k][k] Eliminación: A[i][j] = A[i][j] − m·A[k][j] Sustitución: x[i] = (b[i] − Σ A[i][j]·x[j]) / A[i][i]

Calculadora Interactiva

① Tamaño n
② Matriz aumentada (A|b)
Ingresa los coeficientes. La última columna es b.

Código Java

Gauss.java
import java.util.Scanner;
public class Gauss {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        double[][] A = new double[n][n]; double[] b = new double[n];
        for(int i=0;i<n;i++) for(int j=0;j<n;j++) A[i][j]=sc.nextDouble();
        for(int i=0;i<n;i++) b[i]=sc.nextDouble();
        // Eliminación hacia adelante
        for(int k=0;k<n-1;k++)
            for(int i=k+1;i<n;i++){
                double f=A[i][k]/A[k][k];
                for(int j=k;j<n;j++) A[i][j]-=f*A[k][j];
                b[i]-=f*b[k];
            }
        // Sustitución hacia atrás
        double[] x=new double[n];
        for(int i=n-1;i>=0;i--){
            double s=0;
            for(int j=i+1;j<n;j++) s+=A[i][j]*x[j];
            x[i]=(b[i]-s)/A[i][i];
        }
        for(int i=0;i<n;i++) System.out.println("x"+(i+1)+"="+x[i]);
    }
}

UNIDAD 3 › GAUSS-JORDAN
Gauss-Jordan

Reduce la matriz aumentada a la identidad, obteniendo la solución directamente sin sustitución hacia atrás.

🎯
Resultado
Matriz Identidad
💻
Lenguaje
Python

Fórmulas

Normalización: A[i][j] = A[i][j] / pivote Eliminación: A[k][j] = A[k][j] − factor·A[i][j] (k≠i) Solución: x[i] = A[i][n]

Calculadora Interactiva

① Tamaño n
② Matriz aumentada (A|b)
Última columna = vector b.

Código Python

GaussJordan.py
def gauss_jordan(A, b):
    n = len(A)
    # Matriz aumentada
    M = [A[i] + [b[i]] for i in range(n)]
    
    for i in range(n):
        pivot = M[i][i]
        # Normalizar fila
        for j in range(n + 1):
            M[i][j] /= pivot
            
        # Eliminación en otras filas
        for k in range(n):
            if k != i:
                factor = M[k][i]
                for j in range(n + 1):
                    M[k][j] -= factor * M[i][j]
                    
    # Extraer solución
    return [M[i][n] for i in range(n)]

UNIDAD 3 › GAUSS-SEIDEL
Gauss-Seidel

Método iterativo que actualiza cada variable inmediatamente al calcularla, convergiendo más rápido que Jacobi.

⚡
Velocidad
~2× más rápido que Jacobi
💻
Lenguaje
Java

Fórmula

xᵢ = (bᵢ − Σⱼ≠ᵢ aᵢⱼ·xⱼ) / aᵢᵢ (actualización inmediata)

Calculadora Interactiva

① Tamaño n
② Matriz A y vector b
③ Parámetros
TOLERANCIA
MÁX. ITER

Código Java

GaussSeidel.java
public class GaussSeidel {
    public static double[] solve(double[][] A, double[] b, double tol, int maxIter) {
        int n = b.length;
        double[] x = new double[n];
        for (int k = 0; k < maxIter; k++) {
            double err = 0;
            for (int i = 0; i < n; i++) {
                double s = 0;
                for (int j = 0; j < n; j++) {
                    if (j != i) s += A[i][j] * x[j];
                }
                double xNew = (b[i] - s) / A[i][i];
                err += Math.abs(xNew - x[i]);
                x[i] = xNew; // Actualización inmediata
            }
            if (err < tol) break;
        }
        return x;
    }
}

Método de Jacobi

Método iterativo que usa únicamente valores de la iteración anterior para actualizar todas las variables simultáneamente.

✅

Código Java

Jacobi.java
public class Jacobi {
    public static double[] solve(double[][] A, double[] b, double tol, int maxIter) {
        int n = b.length;
        double[] x = new double[n];
        double[] xNew = new double[n];
        for (int k = 0; k < maxIter; k++) {
            double err = 0;
            for (int i = 0; i < n; i++) {
                double s = 0;
                for (int j = 0; j < n; j++) {
                    if (j != i) s += A[i][j] * x[j];
                }
                xNew[i] = (b[i] - s) / A[i][i];
                err = Math.max(err, Math.abs(xNew[i] - x[i]));
            }
            System.arraycopy(xNew, 0, x, 0, n); // Actualización simultánea
            if (err < tol) break;
        }
        return x;
    }
}
